# Megabuyte export styling (subscriber edition)

Derived from the Megabuyte Design System and the Research Keynote / Board Briefing system (2026). Both share the same brand: crimson-pink accent, Lato, charcoal and warm greys. This file adapts them for exports that subscribers generate. Where the two disagree, this file decides.

Apply it only to **files exported from Megabuyte MCP data** by a skill in this suite: Word, Excel, PowerPoint and PDF. Never apply it to anything else the user makes, even in the same conversation.

## Setup (once per session, before writing any file)

```bash
python <this skill's directory>/scripts/brand_setup.py
```

The script installs Lato and copies the official logos to `/tmp/mb_brand/`: `logo_white.png` (on charcoal) and `logo_pink.png` (on white). Both are transparent with a 4.36:1 aspect ratio. Size them by height, and never recolour, crop or retypeset the mark.

## Lockup, attribution and disclaimer (required on every export)

**Fixed text.** Use these exactly. Don't reword them.

- `ATTRIBUTION` (mandated by the Content Usage Guidelines): **Source: Megabuyte www.megabuyte.com**
- `FOOTER`: **Source: Megabuyte www.megabuyte.com. AI-generated from Megabuyte research and data; not reviewed by Megabuyte. Not investment advice. Data as of [date].**
- `FOOTER_SHORT` (slides only, where the full footer won't fit on one line at 10pt): **Source: Megabuyte www.megabuyte.com. AI-generated; not reviewed by Megabuyte. Not investment advice.** On decks, the data date goes on the title slide and the closing page instead.
- `CUG_URL`: **https://mb-legal.s3.eu-west-1.amazonaws.com/Megabuyte-Content-Usage-Guidelines+-+V5+Final.pdf**. This is a versioned file; replace it here, and nowhere else, when a permanent address exists.

**Rules:**
- **Lockup:** the logo plus "Prepared with Megabuyte data", on the document header, the first slide and the spreadsheet title bar.
- **Never** write "Megabuyte research report", "Megabuyte report" or "by Megabuyte", and never present the output as Megabuyte's own work or opinion.
- **Never** use the research decks' fixed opening frame (About us, Some of our subscribers) or subscriber logos.
- **Footer** on every page, slide and sheet: `FOOTER`, or `FOOTER_SHORT` on slides.

Replace `[date]` with the data date.

**Layout by format:**
- **Word:** start a new page. Use the eyebrow and title as in the title block, then the four paragraphs at 9pt ink with 1.15 spacing, and the bold lead-ins in ink (the only bold allowed in body text). End with `ATTRIBUTION` in 9pt mute.
- **PowerPoint:** a light content slide. Use the eyebrow and title as in the header, then the paragraphs in two columns at 12pt (the body floor), with a page number.
- **Excel:** column A about 110 characters wide with text wrapping. Row 1 is the title bar, and from row 3 there is one paragraph per row, with the lead-in as bold rich text if available, otherwise in the same cell. Set row heights so nothing is cut off.

## Palette

Never pure black and never pure-white body text. Pink is the only accent.

| Token | Hex | Use |
|---|---|---|
| Charcoal | 1D1D1D | Dark surfaces: Word header bar, Excel title bar, dark slides |
| Ink | 131313 | Body text, table header labels, table header rule |
| Paper | FFFFFF | Page and light slide background |
| Canvas | F2F2F2 | Table header fill and card fill only, never a page or slide background |
| Pink | FF004D | The single accent: rules, eyebrows, bullets, the subject's series, one standout figure |
| Pink tint | FFF0F4 | Hero/total row fill only (the 6% pink tint) |
| Mute | 606060 | Captions, source notes, footers, axis labels, peer columns |
| Mute 2 | 868685 | Subtitles, reference lines |
| Line | DEDEDE | Structural hairlines, card borders |
| Line soft | EEEEEE | Table row hairlines, chart gridlines |
| Text on dark | E4E4E4 | Secondary text on charcoal, including the lockup |
| Chart greys | C7C7C7, A8A8A8 | Context series in charts |

No blue, green or amber anywhere, links included (links are ink, underlined). The one exception is the four-colour categorical set for line charts below.

## Type

Lato only. Weights: 900 for the title, 700 for headings, eyebrows and table heads, 400 for body. Arial is the only fallback; never name another font (see "Fonts on the recipient's machine").

- **Headings and titles:** sentence case, short (2–6 words on slides).
- **Eyebrows and labels:** UPPERCASE, 700, wide tracking (character spacing about +1pt).
- **Emphasis:** pink on the pivotal words only. No bold inside body text, no italics in body (italics only for source notes), no underlines except links.
- **Figures:** explicit units and periods (£24.8m, +38%, 3.2×, FY Mar-25).
- **Bullets:** pink markers, never default discs: a pink en dash (–) in Word, a pink square in PowerPoint.

## Tables (all formats)

- Header row: canvas fill, ink UPPERCASE 700 labels, and a 1.5pt ink rule beneath it.
- Rows: 1pt line-soft hairlines between rows. **No vertical rules and no alternating row fill.**
- Figures right-aligned, text left-aligned. Use "—" for not held, never 0.
- **Subject vs peers:** the subject's values stay ink; peer or comparison values are set in mute grey. Don't fill the subject's row.
- **At most one hero row**, usually a total or the key result: pink-tint fill, a 2pt pink bottom rule, ink bold text, and its one standout figure in pink.
- A source note directly under each table: mute, italic, smallest size used in the format.

## Charts (all formats)

Decide first whether the chart has a hero series.
1. **A hero series (the default):** the series the title is about is pink. Context series use C7C7C7, then A8A8A8. Never ink or black.
2. **No hero, categories to separate** (stacked, share or column charts): use the pink-tint ramp from light to dark, FFC2D2, FF7CA0, FF3D75, FF004D, with the deepest step on the segment to emphasise.
3. **No hero, equally weighted lines (line charts only, at most four series):** FF004D, 3D51C4, 158F86, D67A16, with end labels matched to each line's colour.

Further rules:
- Gridlines EEEEEE; axis labels mute; labels in preference to a legend; figures shown on bars where they fit.
- No 3D, shadows or chart borders.
- Benchmark series in A8A8A8. Fixed reference lines are a solid 1pt 868685 line labelled at the right end, never dashed. Dashes mean forecast only.

## Word (.docx, docx npm)

- **Page:** A4, margins 1000 DXA, content width 9906 DXA.
- **Header bar:** a full-width single-cell table with a charcoal fill and no borders. Inside it, the white logo at 26px height (about 113×26) on the left, and "Prepared with Megabuyte data" on the right in 8pt text-on-dark, set with a right tab stop. Under the bar, add the short pink rule: a one-cell table 1080 DXA wide with a pink fill and an exact row height of 90 twips. Put an empty paragraph with exact line height between the two tables, or Word merges them into one.
- **Title block** (below the pink rule):
  - a pink UPPERCASE eyebrow (e.g. "COMPANY BRIEF") at 9pt, 700, tracked;
  - the title in Lato Black at 22pt, ink;
  - the entity and date line at 9pt, mute 2.
- **Section headings:** 12pt Lato Bold, ink, sentence case, using `HeadingLevel.HEADING_2`, with 12pt space before and no underline rule. Body text is 10pt ink with 1.15 line spacing (`line: 276`).
- **Bullets:** a numbering config with a pink en dash (–). Lato has no ▪ glyph, so a square forces a fallback font and breaks the indent.
- **Footer:** 8pt mute, with the page number as "Page N".

## Excel (.xlsx, openpyxl)

- **Row 1, every sheet:** a charcoal title bar across all used columns, height 30, no pink border.
  - A1: a short title (under about 40 characters) in white Lato Bold 14pt.
  - The last column: "Prepared with Megabuyte data", right-aligned, in E4E4E4 9pt.
  - The Summary sheet also carries the white logo in the bar at 22px height, anchored mid-bar with a `OneCellAnchor`. This needs `pillow`; skip the logo if it fails.
- **Row 2:** subtitle in mute italic 9pt. Row 3 is empty, and row 4 starts the content.
- **Headers:** canvas fill, ink bold UPPERCASE labels, a medium ink bottom border, height 22, frozen below.
- **Rows:** EEEEEE thin bottom border, no fills, no vertical borders. Gridlines hidden. Right-align the headers of numeric columns, and indent a text column that follows a numeric one (indent 2), so figures and text don't run together.
- **Formatting:** sources from Megabuyte and formulas are both in ink. Explain any convention in a notes cell rather than with colour.
- **Print:** landscape, fit to width.

## PowerPoint (.pptx, pptxgenjs)

- **Layout:** `LAYOUT_WIDE` (13.33×7.5in). The source system's px values halve to pt, so 24px means 12pt.
- **Two backgrounds only:** paper for content slides, charcoal for the title slide (and a closing slide, if one is used). Canvas is never a slide background.
- **Title slide (charcoal), bottom-anchored:**
  - the white logo top-left at 0.55in height;
  - at the bottom margin, a pink UPPERCASE eyebrow (11pt) above a 0.5×0.04in pink rule;
  - the title at 44–60pt Lato Black, white;
  - the subtitle at 16pt in mute 2;
  - "Prepared with Megabuyte data" in text-on-dark at 11pt.
  - No page number.
- **Content slides (paper):**
  - a header with a pink UPPERCASE eyebrow naming the section (e.g. "POSITIONING") at 11pt, and under it a sentence-case title at 28pt Lato Bold, ink, of 2–6 words. Margins are 0.85in at the sides and 0.65in at the top.
  - a footer rail 0.35in from the bottom: the pink logo at 0.18in height on the left, `FOOTER_SHORT` centre-left at 10pt mute, and the page number on the right as "02" at 10pt mute.
  - put the footer and logo on the master (`defineSlideMaster`). Add the page number to each content slide as text (`String(n).padStart(2, '0')`): the slide-number field can't show "02".
- **Bullets:** use `bullet: { code: '25AA' }`. pptxgenjs can't colour bullets, so `finish_export.py` (run last) turns them pink in Arial, which has the square glyph.
- **Size floors:** body 12pt, chart introduction text 13pt, eyebrows 11pt, sources and footnotes 10pt. Nothing below 10pt.
- **Text boxes:** fixed size with autofit off. If text overflows, cut words; don't shrink the type.
- **Cards:** white fill, 1pt line border, 0.12in corner radius (`rectRadius`), soft shadow (blur 8, offset 2, opacity 0.08). A key card is marked with a pink eyebrow or a short pink rule inside it.
- **Content:** one idea per slide, and method and coverage on their own slide.

## Fonts on the recipient's machine

Exports are opened on machines that may not have Lato installed. Handle that in three ways.

1. **Run `finish_export.py` on every Word, PowerPoint and Excel file, as the very last step.** For .pptx, run it after `applyTheme`; for .xlsx, after `recalc.py`, since LibreOffice rewrites the styles.
   ```bash
   python <this skill's directory>/scripts/finish_export.py <file.docx|file.pptx|file.xlsx>
   ```
   - **Word:** embeds Lato Regular, Bold, Italic and Black, with Arial named as the fallback. This adds about 300 KB and is verified in Word on a machine without Lato. Lato's open font licence permits embedding (`assets/fonts/OFL.txt`).
   - **PowerPoint:** embeds no fonts. PowerPoint rejects them with an "Install Embedded Fonts – General Failure" dialog. Instead, the script gives every Lato reference, theme included, the same Arial-class substitution hint, and turns bullets pink.
   - **Excel:** can't embed fonts. The script sets every font, including the base Normal style, to Lato with the sans-serif family hint, and removes theme-font links.
   - Only Word can name a fallback outright. PowerPoint and Excel can only hint, which in practice steers Office to Arial. On Microsoft 365, Lato often arrives as a cloud font anyway.
   - Re-run the format's validator afterwards.
2. **Keep layouts Arial-safe.** Arial sets about 2.5% wider than Lato (x-height 0.528 vs 0.506), so a layout that fits Lato almost always fits Arial.
   - Leave at least 5% slack in fixed-size text: slide text boxes, table cells, Excel column widths.
   - Never size a box to the exact width of Lato text.
   - This matters most for Excel, and for viewers that ignore embedded fonts (Google Docs and Slides, some web and mobile viewers).
3. **Offer a PDF copy.** After any Word or PowerPoint export, end with a one-line offer of a PDF copy. If the user accepts, run:
   ```bash
   python <this skill's directory>/scripts/export_pdf.py <file>
   ```
   The script reports whether Lato is embedded in the PDF. If it warns that Lato is not embedded, re-run `brand_setup.py` and try again. A PDF is the only format that guarantees the exact look on any machine.

## Page-length note

If a Word export ends with a mostly empty last page, it's usually caused by heading rules and spacing, not the font. Fold the sources line into a note under the coverage notes rather than giving it its own heading.

## QA

Render every export to images and check:
- the logo is crisp and correctly coloured for its background;
- the lockup is present, `FOOTER` (or `FOOTER_SHORT` on slides) is on every page, slide and sheet, and the Important information page closes the export;
- there's no pure black, no blue, no alternating row fill and no vertical table rules;
- pink appears only on rules, eyebrows, bullets, the subject or hero series and one standout figure;
- nothing on a slide is below 10pt;
- `finish_export.py` ran last on every file and reported success for each, and the validator still passes. LibreOffice renders are lenient: PowerPoint ignored mis-ordered bullet colours that LibreOffice showed as pink. Any change to the post-processing scripts needs a check in real Office.
